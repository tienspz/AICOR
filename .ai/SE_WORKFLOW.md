# Software engineering workflow

Requirements: trace features to the authoritative SRS, preserve scope, and define acceptance criteria.

Design: review architecture, data flow, interfaces, provenance, and decision records.

Implementation: make small changes with clear responsibilities and minimal dependencies.

Testing: use unit, integration, E2E, data-quality, and regression tests when meaningful; validate append-only behavior and statistical edge cases.

Quality: run static analysis, review error handling, document reproducible commands, and never claim unrun checks.

Release: verify builds, workflows, deployment configuration, secret handling, and rollback considerations.
